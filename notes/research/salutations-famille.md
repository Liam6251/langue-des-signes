# Recherche : salutations, politesse, questions, personnes, famille

Fichier de données : `js/data/salutations-famille.js` (52 signes).

## Sources utilisées

1. **Wikisign LSF** (https://lsf.wikisign.org/wiki/…) : wiki collaboratif avec une description écrite
   du signe (configuration, mouvement). C'est la source principale. Elle est collaborative et ancienne
   (2008–2020), donc la plupart des fiches sont « probable » et non « sur ».
2. **Notes de cours LSF 1er niveau** (http://stfuscientt.free.fr/LSF/LSF.html) : prises de notes d'un
   élève, région inconnue. Je m'en suis servi seulement pour confirmer ou compléter (QUAND, OÙ, COMMENT,
   GARÇON, PARENTS, COMBIEN, PARDON).
3. **University of Rochester, dictionnaire LSF-ASL** (https://projects.lib.rochester.edu/lsf-asl/) :
   seule description écrite trouvée pour QUI.
4. **Elix** (https://dico.elix-lsf.fr) : les pages n'ont que des vidéos, sans texte lisible ici.
   Elix est cité pour MON et TON, qui viennent de connaissances générales (main plate sur la poitrine
   ou vers l'autre). C'est la référence vidéo à utiliser pour vérifier.
5. Écartées : walter-learning.com et clic-campus.fr (descriptions vagues, mélangées avec l'ASL),
   letribunaldunet.fr (« maman » au menton avec le pouce : c'est le signe ASL).

## Signes non faits (pas de description fiable trouvée)

enchanté, bienvenue, je m'appelle / comment tu t'appelles (NOM/S'APPELER : WS donne seulement « U »),
quel (mis comme synonyme de QUOI), excuse-moi et désolé (mis comme synonymes de PARDON),
copain/copine (synonymes de AMI), personne, enfant (WS : « description à ajouter »),
entendant (WS : seulement la configuration K), oncle, tante (WS : seulement la configuration T),
cousin(e) (seulement la configuration C), adolescent.
